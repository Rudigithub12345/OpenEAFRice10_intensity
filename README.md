# OpenEAFRice10_intensity
Mapping rice cropping intensity across East Africa: Source Code

This repository contains scripts and workflows for mapping rice cropping intensity across East Africa using multi-temporal Sentinel-1 and Sentinel-2 satellite imagery in Google Earth Engine (GEE), a cloud-based geospatial processing platform. The outputs include high-resolution annual rice cropping intensity maps at 10 m spatial resolution, enabling the identification of single- and double-cropping rice systems.

These maps provide consistent, open-access, and reproducible datasets to support food security assessments, agricultural monitoring, and climate-related research.
